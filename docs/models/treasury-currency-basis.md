# TreasuryCurrencyBasis

`original` informa la moneda nativa de cada cuenta. `functional_ars` informa el valor contable funcional en ARS.

## Example Usage

```typescript
import { TreasuryCurrencyBasis } from "lapyme/models";

let value: TreasuryCurrencyBasis = "functional_ars";
```

## Values

```typescript
"original" | "functional_ars"
```
